# Repositories

| Repository | Visibility | Contents |
| --- | --- | --- |
| `homelab` | Public | Architecture, roadmap, and sanitized documentation |
| Private infrastructure repo | Private | Authoritative infrastructure as code, workflows, runbooks, and evidence |

Infrastructure files never go in the public repository. Public material describes generalized patterns. Implementation and operational detail stay in the private infrastructure repo. See [Architecture](architecture.md) for the disclosure boundary.

A rename of the private infrastructure repo is planned but has not been done.
