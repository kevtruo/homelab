# CLAUDE.md

This is the public Homelab repository: architecture, roadmap, and sanitized documentation. It contains no infrastructure files.

Read before working here:

- [Operating model](docs/operating-model.md): roles, flow, completion states, and principles
- [Repositories](docs/repositories.md): what belongs in the public and private repositories
- [Initiatives](docs/initiatives.md): codewords, sprint IDs, and labels
- [Architecture](docs/architecture.md): conceptual model and disclosure boundary
- [Tracking procedure](docs/tracking.md): sprint entry steps, field reconcile, and sprint review

Execution sessions stop at the pull request. They do not merge or push to `main`.

Never commit cloud account or organization identifiers, resource names, GitHub App identifiers, access role or environment names, local or log paths, or chat channel names. Check every diff for these before pushing.
