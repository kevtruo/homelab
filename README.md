# Homelab

A personal homelab for learning cloud security, identity, security analytics, and operations automation.

This repository provides an overview of the project and its engineering principles. Implementation is maintained in the repositories that own each component.

See [Architecture](docs/architecture.md) for the conceptual model and public disclosure boundary, [Initiatives](docs/initiatives.md) for initiative codewords and work ID conventions, [Operating model](docs/operating-model.md) for how work moves from planning to verified completion, [Repositories](docs/repositories.md) for public and private repository boundaries, [Tracking procedure](docs/tracking.md) for how sprint work is tracked, [Code review](docs/code-review.md) for the review standard every pull request meets, and [AI contributor](docs/ai-contributor.md) for the bot contributor model and its guardrails.

## Work tracking

GitHub Projects tracks the roadmap, priorities, and progress across repositories. Issues define actionable work; pull requests implement changes.

Project and architecture Issues belong here. Implementation Issues belong in the repository that owns the change.
